components that are actually compiled into or distributed with the
shipped VST3 plugin. It does not list development-only tooling (build
system, test frameworks, or QA/validation utilities such as pluginval)
that never ships to end users.

5. Microsoft Edge WebView2
----------------------------
https://developer.microsoft.com/microsoft-edge/webview2/

UNI 76's user interface (Resources/Web/) renders inside a WebView2
control. Only the small WebView2Loader component is statically linked
into the plugin binary (see Source/Plugin/CMakeLists.txt's
JUCE_USE_WIN_WEBVIEW2_WITH_STATIC_LINKING) - the actual browser engine
(the WebView2 Runtime) is a separate, shared system component that
Microsoft distributes and updates independently (most current Windows
10/11 installations already have it, since Windows/Edge install it as a
shared component). UNI 76 does not bundle, modify, or redistribute the
runtime itself. See Packaging/Windows/README.md's "WebView2 Runtime"
section for the installer's detection/fallback behaviour.


No other third-party source code, libraries, fonts, or media assets are
bundled with UNI 76. The user interface (Resources/Web/*.html/*.css/*.js)
is original, project-authored code with no external JS libraries, no
external fonts, and no CDN dependencies (see CLAUDE.md's "HTML/CSS/JS UI
rule").
