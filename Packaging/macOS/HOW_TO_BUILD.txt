UNI 76 - сборка на macOS
=========================

Подробная инструкция для того, кто будет собирать плагин на Mac. Плагин
называется "UNI 76", это VST3 audio-эффект (JUCE + CMake).


ШАГ 0. Что скинуть

Отправь другу папку проекта ЦЕЛИКОМ, КРОМЕ подпапки "build" (её не
отправляй - она весит несколько гигабайт, это Windows-сборка и весь
скачанный исходник JUCE, на Mac всё равно соберётся заново с нуля).
Тот, кто отправляет, должен зайти в папку "uni76_vst3" и перед архивацией
удалить/не включать вложенную папку "build".

Убедиться, что в присланном архиве точно есть файл "CMakeLists.txt"
прямо в корне папки проекта - если он есть, значит папка правильная.


ШАГ 1. Что нужно установить на Mac (один раз)

1. Xcode - полная версия из App Store (не только "Command Line Tools").
   CMake будет использовать Xcode как генератор проекта, без него ничего
   не соберётся.

   После установки Xcode обязательно один раз открыть его и согласиться
   с лицензионным соглашением (или в Терминале: `sudo xcodebuild -license`).

2. Command Line Tools для Xcode - обычно ставятся автоматически вместе
   с Xcode, но на всякий случай в Терминале:

       xcode-select --install

3. CMake версии 3.25 или новее. Проще всего через Homebrew:

       brew install cmake

   Если Homebrew не установлен - установить его сначала:
   https://brew.sh (одна команда в Терминале с их сайта).

   Проверить версию:

       cmake --version

4. Интернет-соединение - нужно только при ПЕРВОЙ сборке (CMake сам
   скачает исходники JUCE нужной версии, вручную ничего клонировать
   не надо).


ШАГ 2. Сборка

Открыть Терминал, перейти в папку проекта (ту, что прислали - там, где
лежит CMakeLists.txt):

    cd путь/до/папки/uni76_vst3

Настроить сборку (создаст папку build/macos-release):

    cmake --preset macos-release

Это может занять несколько минут в первый раз - CMake скачивает и
настраивает JUCE. Если команда выше не сработала (ошибка про
"unknown preset" или похожую), собрать вручную:

    cmake -S . -B build/macos-release -G Xcode \
        -DCMAKE_OSX_ARCHITECTURES="x86_64;arm64" \
        -DCMAKE_BUILD_TYPE=Release

Теперь собрать сам плагин (Release-конфигурация):

    cmake --build build/macos-release --config Release

Тоже несколько минут (компилируется JUCE + сам плагин). Если сборка
падает с ошибкой - см. раздел "Если что-то пошло не так" ниже.


ШАГ 3. Где готовый плагин

После успешной сборки .vst3-бандл лежит здесь:

    build/macos-release/Source/Plugin/UNI76_artefacts/Release/VST3/UNI 76.vst3

Это и есть готовый плагин - целая папка с расширением .vst3 (это не один
файл, а "бандл", как .app - так и должно быть).


ШАГ 4. Установка в систему (чтобы DAW его увидел)

Самый простой способ - готовый скрипт, он сам скопирует куда нужно:

    ./Packaging/macOS/dev-install.sh Release

Он копирует .vst3 в стандартную системную папку

    ~/Library/Audio/Plug-Ins/VST3/

которую сканируют все основные DAW на Mac (Ableton Live, Logic Pro,
Cubase, Reaper, Studio One и т.д.).

Если скрипт не запускается ("Permission denied"), сначала дать ему
права на выполнение:

    chmod +x ./Packaging/macOS/dev-install.sh
    ./Packaging/macOS/dev-install.sh Release

Альтернатива вручную (если скрипт по какой-то причине не работает) -
просто скопировать папку .vst3 из шага 3 в ~/Library/Audio/Plug-Ins/VST3/
через Finder (Cmd+Shift+G в Finder, вставить путь ~/Library/Audio/Plug-Ins/VST3/).

После копирования нужно перезапустить DAW (или заставить её пересканировать
плагины - в большинстве DAW это делается в настройках плагинов).


ШАГ 5 (не обязательно). Прогнать тесты

Если хочется убедиться, что вся DSP-логика работает правильно перед тем
как слушать плагин в DAW:

    ctest --test-dir build/macos-release -C Release --output-on-failure

Должны пройти все тесты без единого FAILED. Это не обязательный шаг,
плагином можно пользоваться и без него.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

- Ошибка про отсутствующий компилятор / "no CMAKE_CXX_COMPILER" -
  не установлен Xcode или Command Line Tools (см. Шаг 1, пункты 1-2).

- Ошибка "cmake: command not found" - CMake не установлен или не
  добавлен в PATH (переустановить через Homebrew, см. Шаг 1, пункт 3).

- Сборка падает где-то в середине с ошибками компиляции - сфотографировать/
  скопировать текст ошибки целиком и прислать обратно, разберёмся.

- Плагин собрался, но DAW его не видит - проверить, что .vst3 реально
  лежит в ~/Library/Audio/Plug-Ins/VST3/, и что в настройках DAW эта
  папка указана как одна из папок для поиска плагинов (обычно указана
  по умолчанию).

- Первая сборка (ШАГ 2) занимает дольше, чем ожидалось - это нормально,
  JUCE - большая библиотека, компиляция с нуля может занять 5-15 минут
  в зависимости от Mac. Повторные сборки после первой намного быстрее.


ВАЖНО

Эта сборка под macOS ещё НИ РАЗУ не проверялась на реальном Mac - только
настроены CMake-пресеты (Universal Binary под Intel + Apple Silicon
одновременно). Если при сборке или при первом запуске в DAW что-то
пойдёт не так - это будет первая реальная проверка, и там могут
вскрыться проблемы, которых никогда не было на Windows-сборке. Это
нормально для такой ситуации, просто присылайте любые ошибки текстом.
